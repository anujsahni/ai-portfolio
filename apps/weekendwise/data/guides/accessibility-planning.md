# Accessibility and trip constraints

If a traveler provides an accessibility or mobility constraint, preserve it throughout planning and do not infer that a venue, route, or activity is accessible without supporting evidence. Ask what accommodations matter when the request is unclear.

This demo corpus does not verify accessible entrances, elevators, path grades, or service availability. State this limitation and direct the traveler to confirm details with official providers.
