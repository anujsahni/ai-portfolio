# Rainy-day planning pattern

When the traveler requests an indoor alternative for rainy conditions, preserve the original interests and replace or reorder outdoor activities with an indoor option supported by a retrieved guide. Mark the weather result as simulated if it came from the local demo tool.

If no suitable indoor source is retrieved, ask a follow-up or state that the guide set does not support a confident alternative. Do not claim live forecasts or venue availability.
