03 · The architecture · under the hood

Transform & trust

Fivetran-landed raw tablesdbt build · models + testsMarts in DuckDBSemantic layer metricsIceberg snapshotDuckDB · Trino
DD

DuckDB

Warehouse

An embedded analytical database in one file. No server to run.

In this demoHolds the raw landed tables and every dbt model. Act 1's agent queries the raw schemas here; services read a read-only copy.
dbt

dbt Core

Transformation

SQL models with tests, contracts, docs and lineage, run as code.

In this demo27 models: staging → intermediate → marts. Each trap is fixed in a named model, such as int_delivery_actuals, and guarded by a test.
MF

Semantic layer

MetricFlow

Metrics defined once in YAML. The SQL is generated, never hand-written.

In this demo8 metrics, such as on_time_delivery_rate and net_revenue. Every number the agent reports is compiled here.
IC

Apache Iceberg

Open table format

Parquet files plus metadata and snapshots, in a catalog any engine can read.

In this demoPyIceberg publishes the 6 marts to northstar.marts after every build: REST catalog, files in RustFS (S3).
TR

Trino

Second engine

A distributed SQL engine that queries Iceberg through its connector.

In this demoRuns the at-risk query on the same Iceberg table as DuckDB and returns identical rows: store once, read anywhere.

MCP

MCP

Model Context Protocol

An open standard for giving an agent tools and context through one interface.

In this demoThree MCP servers in private containers, over streamable HTTP. The agent sees only their tools.
dbt

dbt MCP server

Meaning · lineage

The official dbt-mcp server from dbt Labs.

In this demoRead-only tools only: list, get_node_details_dev, get_lineage_dev, from the latest build's manifest.
M

Metrics server

Governed numbers

A small MCP server over the semantic layer.

In this demolist_metrics returns the definitions; query_metric has MetricFlow compile the SQL and returns it with the rows.
F

Freshness server

Data age

A small MCP server over the Fivetran sync log.

In this democheck_freshness: last sync, age and errors per source. It finds Zendesk two days behind its 24-hour window.
C

Claude

The agent

The same model as Act 1. Only its context changes.

In this demoA small bridge (the Python MCP client) hands the servers' tools to Claude's tool use. No raw-table access.
